# tasometro-noticias

Noticias diarias de finanzas personales para Argentina que publica [tasometro.com.ar](https://tasometro.com.ar).

`noticias.json` → `noticias[]`: cada nota con `slug`, `categoria` (`mercado-argentino`, `mercado-internacional`, `tasas`, `dolar`, `inflacion`), `titulo`, `h1`, `descripcion`, `resumen`, `publicado`, `modificado`, `cuerpo` (HTML simple), `datos_clave`, `faqs`, `fuentes` y `relacionados`. El sitio lo lee cada 3 horas y publica las notas nuevas.
